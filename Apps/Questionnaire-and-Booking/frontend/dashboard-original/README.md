# Retired contact dashboard prototype

[Frontend guide](../README.md) → [Active dashboard](../dashboard/README.md) → **Archived prototype**

These three files preserve the previous contact-dashboard implementation. They are a design/implementation reference; `serve-local.js` serves the [Lead Intelligence app](../dashboard/README.md) from `dashboard/` on port 3002.

The active dashboard replaces the old run/contact table with six pages, a stitched lead drawer, scores, flags and triage actions. See its [screenshot walkthrough](../dashboard/README.md#screenshot-walkthrough) and [Tools](../../Tools/README.md) for the current browser checks.
